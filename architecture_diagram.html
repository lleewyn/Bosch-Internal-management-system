Bosch internal management system Architecture

Kiến trúc hệ thống Quản lý Nhân sự & Vận hành nội bộ BGSV (Serverless Frontend + Supabase BaaS)

Client UI Architecture

  • • HTML5 + Vanilla CSS3 layout
  • • Pure Javascript (ES6+) controller logic
  • • client-side guards in router.js
  • • localstorage user-session cache
  • • Chart.js visualization reporting
  • • jsPDF and SheetJS data exports

Backend (Supabase BaaS)

  • • Hosted serverless database architecture
  • • PostgREST instant REST API mapping
  • • Supabase Storage file-bucket management
  • • Secure session JWT distribution
  • • Auto backup schemas & scaling

Database & Security

  • • PostgreSQL relational table schemas
  • • Row-Level Security policy enforcement
  • • Auto audit-log generation on mutations
  • • User accounts brute-force lock protection
